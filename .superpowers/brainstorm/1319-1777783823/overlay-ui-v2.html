工具栏功能说明

语言选择

原语言：默认"自动检测"，也供 OCR 指定识别语言
目标语言：翻译输出语言，影响翻译引擎调用
语言选择持久化到配置文件

引擎切换

OCR 引擎：下拉选择已配置的 OCR 引擎
翻译引擎：下拉选择已配置的翻译引擎
切换后自动重新执行 OCR + 翻译

操作按钮

重选：清除选区，回到 S2 重新框选
显示原文：切换显示原文/译文覆盖层
复制原文：将 OCR 识别的原文复制到剪贴板
复制译文：将翻译结果复制到剪贴板
退出：关闭覆盖层，回到托盘

交互细节

工具栏位于选区下方，自动避让屏幕边缘
下拉菜单点击展开，选择后自动收起
引擎切换时显示加载状态
"显示原文"为切换按钮（原文 ↔ 译文）
