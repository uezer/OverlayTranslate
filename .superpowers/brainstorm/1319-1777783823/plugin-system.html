插件化引擎架构

OCR 和翻译引擎的接口设计与加载机制

引擎接口定义

IOcrEngine

interface IOcrEngine
├─ Name: string
├─ IsAvailable: bool
├─ RecognizeAsync(image, options)
│ └─ → OcrResult
└─ GetSupportedLanguages()
└─ → string[]
class OcrResult
├─ TextBlocks: List<TextBlock>
├─ FullText: string
└─ Language: string
class TextBlock
├─ Text: string
├─ BoundingBox: Rect
├─ Confidence: float
└─ Angle: float

ITranslationEngine

interface ITranslationEngine
├─ Name: string
├─ IsAvailable: bool
├─ TranslateAsync(text, from, to)
│ └─ → TranslationResult
└─ GetSupportedLanguages()
└─ → string[]
class TranslationResult
├─ TranslatedText: string
├─ SourceLanguage: string
└─ EngineName: string
引擎注册与发现机制

加载流程

1. 启动时扫描 Engines/ 目录
2. 通过 DI 注册所有引擎实现
3. 读取 JSON 配置中的用户选择
4. 按优先级排序引擎列表
5. 运行时按策略选择引擎

选择策略

仅本地：只使用本地引擎
本地优先：本地失败时回退远程
仅远程：只使用远程 API
自定义顺序：用户拖拽排序
