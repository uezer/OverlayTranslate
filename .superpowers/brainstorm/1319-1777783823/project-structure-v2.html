Python 依赖策略
• C# 生态成熟的库 → 直接用 C# (如 PaddleOCRSharp、OpenCvSharp)
• C# 缺失或实现困难的 → 通过 Python.NET 调用 Python 库
• Python 运行时路径在 appsettings.json 中配置
• PythonRuntime 负责初始化/释放 Python 引擎，生命周期跟随 App
